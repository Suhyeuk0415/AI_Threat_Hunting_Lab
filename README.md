# 🛡️ AI-Threat-Hunting-Lab
**최신 웹/API 취약점 환경 구축 및 AI 에이전트 한계 분석 시뮬레이션**

## 🎯 프로젝트 목적
최신 AI 모의해킹 툴이 식별하는 취약점의 오탐(False Positive)을 정보보안기사 지식을 바탕으로 교차 검증하고, 툴의 한계를 인간의 분석(Bypass)으로 극복합니다. 나아가 이를 방어하기 위한 백엔드 시큐어 코딩 및 인프라 보안(SELinux, 방화벽) 강화 방안을 도출합니다.

## 🛠️ 기술 스택 (Tech Stack)
- **Attacker (AI)**: Kali Linux, AI Penetration Testing Tools
- **Target Infra**: Rocky Linux (CLI/GUI), Apache, PHP
- **Vulnerabilities**: LFI to RCE, API BOLA (Broken Object Level Authorization)
